# dojo

A repo for building stuff without letting your AI do the fun part.

You write the code. The agent helps when you get stuck.

It can explain things, review your code, ask questions, help debug, point you at docs, and give hints.

It cannot write the project for you.

That’s basically the whole thing.

## why

I use AI a lot when coding. Probably too much.

It’s useful, but it’s also very easy to go from “this saves me time” to “wait, could I still build this myself?”

So this repo is where I don’t let it.

Pick a project. Write the ugly version. Get stuck on something dumb. Read docs. Ask for a hint. Eventually make it work.

## how it works

1. Clone the repo.
2. Open it with your coding agent.
3. The agent asks what kind of stuff you want to build.
4. Pick a project.
5. Build it.

If you ask for help, the agent starts with small hints and gets more specific if needed.

Worst case, it gives you pseudocode.

Actual code is still your problem.

`NOTES.md` is there for keeping track of what you tried, what broke, and what you finally understood.

## one rule

No AI-written project code.

No exceptions because “it’s just boilerplate.”

Nice try.

## faq

**Can I use AI normally outside this repo?**

Yes lol.

**Can it help with compiler errors / build problems / toolchain nonsense?**

Yep. It can help you figure out what’s wrong.

You still make the change.

**What if I’m completely stuck?**

Keep asking for hints.

The agent can get pretty specific. It just stops before handing you the answer.

**Why would I do this to myself?**

Because struggling with a project is unfortunately where a lot of the learning happens.

Also it’s fun.
